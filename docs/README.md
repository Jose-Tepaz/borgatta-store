## Cómo organizar la información

Crear un archivo Markdown por tema, con nombres descriptivos en minúsculas y guiones, y agregarlo al índice. Por ejemplo: `pedidos-envios.md`, `atencion-clientes.md`, `promociones.md` o `apps-integraciones.md`. Estos son temas sugeridos, todavía no documentados.

Usar la plantilla y registrar únicamente lo que se conozca. Marcar lo que falte como **Pendiente de confirmar**; una propuesta no debe aparecer como una política vigente. Cuando un proceso cambie, actualizar su contenido, fecha y decisiones relevantes.

La documentación puede abarcar catálogo, inventario, pedidos, envíos, pagos, atención al cliente, marketing, reportes, aplicaciones y procedimientos del equipo. Mantener aquí el contexto operativo y enlazar las referencias técnicas donde ya existan.

No incluir credenciales ni datos personales de clientes. Para ejemplos, usar datos ficticios. La documentación no se publica en el storefront ni requiere desplegar el theme por sí sola.
