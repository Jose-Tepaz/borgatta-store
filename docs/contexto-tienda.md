## Gestión del catálogo

El cliente carga y organiza productos en un archivo de catálogo. Este se actualiza automáticamente en Plytix a diario. La lista global observada `Shop Mexico` filtra `Shopify México = INCLUIDO` y se distribuye diariamente mediante el canal `Shopify México`. Esta es la única tienda con ventas; los demás destinos son catálogos poco administrados. Plytix también se usa para crear listas con objetivos específicos.

Ver [Gestión del catálogo](gestion-catalogo.md) para el enlace al archivo, el detalle confirmado y los pendientes.
